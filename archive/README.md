# FIREX v1 — Archived Prototype Directory

This directory contains the legacy **FIREX v1** prototype code, preserved for historical reference and benchmark data fixtures.

> [!NOTE]
> **Active Development Notice:**
> The primary, production-ready system is located in **`v2/`**.
> All active development, backend APIs, modern operator console, spatial clustering, automated triage, and multi-key AI vision analysis reside under **`v2/`**.
> This `archive/` directory is strictly read-only and preserved for archival provenance.

### Directory Structure
- `v1/pipeline/`: Original 7-stage prototype scripts and raw FIRMS response test fixtures.
- `v1/dashboard/`: Original prototype GIS web interface.
- `v1/archive/`: Earliest experimental mock UI and server scripts.
